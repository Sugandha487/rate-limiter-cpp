# Rate Limiter in C++

A C++ project demonstrating rate limiting techniques used to control requests and protect applications from excessive traffic.

## Features

- Request rate control
- Time-based request tracking
- Multiple rate-limiting approaches
- C++ implementation

## Technologies

- C++
- Data Structures
- Algorithms

## How to Run

Compile the program:

g++ RateLimiterService.cpp -o RateLimiterService

Run the program:

./RateLimiterService
